  redesign; DESIGN.md is a summary regenerated from it") turns the fix you made

  since 08-03. Deferring them behind the redesign is fine; the js-yaml class

  pieces exist — babysit-pr to convergence, the Linear plan as the queue an
  agent picks from without re-briefing. Worth using deliberately rather than
  only when time forces it.
